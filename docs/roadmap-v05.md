# Prototype 0.5: consolidated validation

Added explicit scoped UIA actions, a read-only origin-scoped browser navigation loop, offline Windows Sandbox configuration generation, defensive AST leads and authorization matrix, recursive bounded decomposition, fast/deep retry, local Git branch/commit actions, observation context budgeting, OpenVINO measured dispatch, Ollama configuration matrix and offline LoRA training/smoke. Some modules are standalone Python APIs, not all are wired into the conversational CLI. No auto-granted capabilities.

## Validation

Offline tests cover boundaries, graph ordering, context, decomposition, synthetic static precision and fixture workflows. Browser fixture tests use loopback only. Complex model tests use exact oracles for shortest path, event replay, authorization, code diagnosis and data joins. Model security classification measures precision and recall on labeled synthetic snippets, not exploitability. No generated code executed.

## Remaining constraints

No general OS input driver, remote GitHub PR workflow, universal browser form automation, fully enforced OS isolation for the running agent, live OCR/vision integration, advanced offensive engine, production GPU scheduler under concurrent load, patched llama.cpp, or trained adapter for the main 35B model. Windows Sandbox configuration is not proof it was launched. OpenVINO selection measures an auxiliary synthetic model in isolation. LoRA requires compatible local HF safetensors weights and sufficient VRAM; GGUF alone is not a training checkpoint. Keep human review and separate approved execution for side effects. These additions are experimental and must not be presented as full implementation or verified on hardware until reports exist.

Additional tests: constrained arithmetic-code repair using a whitelist AST interpreter and randomized property inputs; long-context retrieval with randomized identifiers; explicit GitHub CLI PR request (no real remote mutation in tests). GitHub workflow includes offline, browser, CPU auxiliary inference and CPU LoRA smoke jobs. A green test on a hosted runner does not validate the user's GPU, Windows UIA, NPU or installed model. The actual main-model adapter training remains opt-in and requires compatible local HF weights and reviewed data.

Final expansion: explicit scoped click/keypress/capture (with confirmation, no general unattended desktop actions), synthetic UIA fixture with text/invoke and physical-input mode, optional Windows Sandbox runtime read-only mapping smoke, explicit GitHub PR request, constrained repair and long-context evaluations. Capture stays local and can include overlapping content. Physical input can race with other desktop activity; do not operate the PC while the fixture runs. Sandbox smoke verifies the mapped input is read-only, not comprehensive OS isolation of Potklin. Browser CI pinned to ubuntu-24.04 for Playwright 1.51 compatibility.

Integrated filesystem create/move/remove (explicit confirmation, no overwrite, expected revision), memory CLI, bounded hierarchical read-only execution, browser field filling without submission, OpenVINO dispatch helper and optional local multimodal probe. Actual desktop and model tests are still workstation-specific. The local filesystem helpers are not a race-proof security boundary and move is not crash-atomic. General browser submission and an actual patched inference engine remain outside this prototype.
